# NOTA DE INTEGRACIÓN CON LA PLATAFORMA BASE (DRY ARCHITECTURE):
# Este slice NO define ni duplica clases base o transversales. Asume que la
# superestructura de plataforma (ver 'tree/template.tree.txt') ya existe y provee
# en 'src/<project_package>/shared_kernel/' los contratos fundamentales:
#
# - Clases Base de Dominio ('shared_kernel/domain/contracts/'):
#     * AggregateRoot             -> src/<project_package>/shared_kernel/domain/contracts/aggregate_root.py (version OCC y Sequence[T] inmutable)
#     * EventSourcedAggregate     -> src/<project_package>/shared_kernel/domain/contracts/event_sourced_aggregate.py
#     * DomainError               -> src/<project_package>/shared_kernel/domain/contracts/domain_error.py
#     * ConcurrencyError          -> src/<project_package>/shared_kernel/domain/contracts/concurrency_error.py
#     * ValueObject               -> src/<project_package>/shared_kernel/domain/contracts/value_object.py (inmutabilidad profunda con freeze_deep)
#     * DomainEvent               -> src/<project_package>/shared_kernel/domain/contracts/domain_event.py (payload y metadata inmutables)
#
# - Infraestructura y Puertos Transversales Consumidos:
#     * UnitOfWorkPort            -> src/<project_package>/shared_kernel/application/ports/persistence/unit_of_work.py
#     * Command / Query Buses     -> src/<project_package>/shared_kernel/application/bus/
#     * RealtimeStreamPort        -> src/<project_package>/shared_kernel/application/ports/messaging/realtime_stream.py (Redis Streams)
#     * EventPublisherPort        -> src/<project_package>/shared_kernel/application/ports/messaging/event_publisher.py (Redpanda / Kafka)
#     * QueuePublisherPort        -> src/<project_package>/shared_kernel/application/ports/messaging/queue_publisher.py (RabbitMQ)
#     * TaskGroup Supervisor      -> src/<project_package>/interfaces/worker/lifecycle/supervisor.py
#     * Transactional Outbox      -> src/<project_package>/shared_kernel/infrastructure/persistence/mssql_or_pg/models/outbox/
#     * Transactional Inbox       -> src/<project_package>/interfaces/worker/inbox/interceptor.py
#     * DistributedLockPort       -> src/<project_package>/shared_kernel/application/ports/concurrency/distributed_lock.py (Redlock)
#     * TenantProvisioner         -> src/<project_package>/shared_kernel/infrastructure/persistence/mssql_or_pg/tenant_provisioning/
#     * Presenter Strategy        -> src/<project_package>/interfaces/common/presenters/
#
# - Integración Contract-First con SDKs de Plataforma ('sdks/'):
#     * Los endpoints en 'interfaces/http/rest/' se etiquetan obligatoriamente con tags=['{{context_slug}}'].
#     * El motor de autogeneración ('sdks/generator/') mapea estos tags directamente hacia namespaces:
#         - Python:     client.{{context_slug}}.<operation>()
#         - TypeScript: client.{{context_slug}}.<operation>()
#     * La suite 'tests/integration/{{context_slug}}/contracts/openapi/' audita la retrocompatibilidad y generación limpia del SDK.
#
# - Inyección de Dependencias y Composition Root ('infrastructure/di/wiring.py'):
#     * Cada slice expone 'register_{{context_slug}}_dependencies(container: Container) -> None'.
#     * Asocia contratos secundarios (ports) con adaptadores físicos (repositories, gateways).
#     * Registra automáticamente los Handlers en el CommandBus y QueryBus dentro del contenedor.
# ==============================================================================
